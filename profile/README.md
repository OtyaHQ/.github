# Otya

Otya is a technology ecosystem building connected digital products and services.

Our public work focuses on useful software, clear product guidance, responsible integrations and reliable experiences.

## Official communications

Official ecosystem email uses **Otya** as the shared sender identity. Product-specific notices follow the central communications, privacy and consent rules; Telegram remains for public announcements, release updates and events.

See the [Otya Standard](https://github.com/OtyaHQ/OEnd/blob/main/docs/architecture/COMMUNICATIONS_STANDARD.md).

## Security

Please report security concerns through the [Otya security policy in OWeb](https://github.com/OtyaHQ/OWeb/blob/main/SECURITY.md). Do not publish credentials, private data or exploit details in public issues.

Otya publishes public documentation and examples here. Private credentials, user data and internal operating procedures do not belong in this repository.
